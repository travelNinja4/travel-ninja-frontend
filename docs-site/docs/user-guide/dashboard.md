# Dashboard

The Dashboard is the agency's home screen: the first page you see after signing in, and where **Back to dashboard** buttons lead.

**Who uses it:** everyone · **Where to find it:** **Dashboard** at the top of the side menu, or straight after signing in

## What it shows today

For now, the Dashboard shows a **Welcome to dashboard** heading inside the usual side menu and header. Use the side menu to reach [Tours](./tours.md), [Bookings](./bookings.md) and [Customers](./customers.md).

There's no summary of tours, bookings or earnings on it yet. This page will be updated when the Dashboard gets its content.

## Things to check when testing

- [ ] Signing in opens the Dashboard with the **Welcome to dashboard** heading.
- [ ] **Dashboard** is highlighted in the side menu and the breadcrumb shows **Dashboard**.
