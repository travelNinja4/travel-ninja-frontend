# Bookings

Bookings will be where the agency sees every seat guests have booked across its tours, and finds a booking by guest, tour, status or date.

**Who uses it:** operations staff handling guests · **Where to find it:** **Bookings** in the side menu

:::caution In development
The Bookings screen is a preview. It shows **sample bookings**, not the agency's real ones, and its search and filters don't change the list yet. Don't use it to check real bookings or to test booking behaviour.
:::

## What the preview shows

- A search box (**Search bookings...**) and filters for **Status**, **Tour**, **Quick Date Filter** and **Date Range**
- An **All Bookings** table with **Booking ID**, **Customer** (name and mobile number), **Tour**, **Date**, **Slots**, **Status** and **Amount**
- Statuses shown as coloured labels: **Confirmed**, **Pending** and **Cancelled**

## Known limitations

- The table shows made-up sample data, with amounts in dollars.
- Search and filters don't affect the table.
- The screen opens without the side menu and header. Use the browser's **Back** button to return.

This page will be rewritten when Bookings is connected to real data.
