# Travel Ninja documentation

Travel Ninja helps tour operators create tours, take bookings and keep track of the guests who book them.

These docs are for:

- **Customers**, who use Travel Ninja day to day. Start with the [User guide](./user-guide/customers.md).
- **The testing team**, who check each release. See [Testing](./testing/how-to-report-a-bug.md) and the [Release notes](./release-notes.md).
