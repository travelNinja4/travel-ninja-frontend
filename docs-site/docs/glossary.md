# Glossary

The business terms used in Travel Ninja and in these docs.

| Term                  | Meaning                                                                                       |
| --------------------- | --------------------------------------------------------------------------------------------- |
| **Agency**            | The tour operator using Travel Ninja. Each agency has its own account, tours and guests.      |
| **Archived**          | A tour that's no longer on sale. It can be viewed or deleted.                                 |
| **Booking**           | A guest's reservation of one or more seats on a tour.                                         |
| **Capacity**          | The number of seats on a tour. Shown on tour cards as _booked/total_, for example **12/16**.  |
| **Category**          | The kind of trip a tour is (for example a beach trip), used to filter the tours list.         |
| **Cover image**       | The main photo of a tour, shown on its card.                                                  |
| **Customer / guest**  | A person who has booked one of the agency's tours.                                            |
| **Departure**         | One run of a tour, with fixed departure and return dates.                                     |
| **Draft**             | A tour that's still being prepared. Guests can't see it, and it can be edited or deleted.     |
| **Gallery**           | Up to 10 extra photos of a tour.                                                              |
| **Guide label**       | The name of the guide leading a tour.                                                         |
| **Itinerary**         | The day-by-day plan of a tour: a title, location and description for each day.                |
| **Occupancy**         | The share of a tour's seats that have been booked, as a percentage.                           |
| **Published**         | A tour that's live: guests can find and book it. It can't be edited or deleted.               |
| **Remember me**       | A sign-in option that keeps you signed in on that device after the browser is closed.         |
| **Total spend**       | The sum a guest has paid across all their bookings with the agency.                           |
| **Verification code** | A 6-digit code sent to the business email or mobile number to prove it belongs to the agency. |
