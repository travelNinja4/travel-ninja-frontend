# How to report a bug

Test each feature against its page in the [User guide](../user-guide/customers.md). Anything that behaves differently from the guide is a bug, or a sign that the guide is out of date.

Include in every bug report:

1. **Screen and URL**: for example `/customers?city=Chennai&page=2`
2. **Steps to reproduce**: numbered, starting from a fresh page load
3. **Expected result**: what the user guide says should happen
4. **Actual result**: what happened, with a screenshot or recording
5. **Environment**: browser and version, screen size, and which build or release you tested
